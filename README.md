# Лабораторна робота №1

Давид Борщук, група КН313.

React 19 + Vite 8, JavaScript, ESLint 10, Prettier.

## Запуск

```sh
npm install
npm run dev
```

## Перевірки

```sh
npm run lint
npm run format:check
npm run build
```

Картка ProfileCard отримує дані через props. Кнопка «Подобається» використовує
useState. Правила агента зберігаються в AGENTS.md. Налаштування VS Code
вмикають ESLint та форматування Prettier під час збереження.
